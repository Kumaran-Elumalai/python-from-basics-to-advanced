# Digital Cookbook Project

I want to build a production-ready Streamlit application called **Digital Cookbook** for the Automotive Manufacturing Industry (Bosch).

## Objective

The application identifies failed components on a product's schematic diagram using Manufacturing Work System (MWS) failure data from Azure Databricks.

The application must be scalable so that adding a new product only requires uploading Master Data. No code changes should be needed.

---

# Technology Stack

* Frontend: Streamlit
* Backend: Python
* Database: PostgreSQL
* ORM: SQLAlchemy
* Production Data: Azure Databricks (MWS)
* File Storage: Local folders (PDF/CAD)

---

# Application Pages

## 1. Application

Operator enters a DMC.

The application should:

* Get Part Number from Databricks.
* Load Master Data from PostgreSQL.
* Retrieve Product, Family, Host IDs, Common Failures, Module Mapping and PDF.
* Query Databricks again using only the uploaded Host IDs.
* Remove pseudo failures.
* Map Modules to Components.
* Highlight Components on the schematic PDF.
* Display and download the highlighted PDF.

## 2. Master Data

Admin page for complete CRUD.

Should support:

* Product
* Family
* Part Number

Uploads:

* Host IDs
* Common Failure Excel
* Module Mapping Excel
* PDF
* CAD

# Runtime Flow

1. User enters DMC.

2. Query Databricks.

SELECT DISTINCT product_part_id

using DMC.

3. PostgreSQL returns

* Product
* Family
* Host IDs
* Common Failures
* Module Mapping
* PDF Path
* CAD Path

4. Use uploaded Host IDs to build the Databricks query.

Uploaded Host IDs may be

CCS7999

while MWS contains

NH1CCS7999

Use pattern matching (or host normalization) so they match.

5. Query Databricks using

* DMC
* mws_test_result=1
* sap_plant_id='1760'
* Allowed Host IDs

6. Retrieve Failed Modules.

7. Remove modules present in Common Failures.

8. Map remaining Modules to Components.

9. Load schematic PDF.

10. Highlight Components.

11. Display and allow download.
